Tentang IPULCLOUD
IPULCLOUD adalah proyek layanan cloud komunitas yang ditujukan untuk membantu pengguna mengenal dan menggunakan lingkungan server jarak jauh melalui Remote Desktop Protocol (RDP) dan Virtual Private Server (VPS).
Informasi ketersediaan, spesifikasi, masa aktif, dan ketentuan akses diumumkan oleh pengelola. Jangan menganggap semua server selalu tersedia atau memiliki sumber daya tanpa batas.
Layanan
RDP
RDP memungkinkan pengguna mengakses desktop komputer/server jarak jauh melalui aplikasi Remote Desktop yang kompatibel.
Contoh penggunaan yang diizinkan: - Belajar menggunakan Windows jarak jauh. - Menjalankan aplikasi yang diizinkan oleh pengelola. - Mengelola file dan pekerjaan pribadi.
VPS
VPS adalah server virtual yang dapat dikelola dari jarak jauh, misalnya melalui SSH untuk sistem Linux.
Contoh penggunaan yang diizinkan: - Belajar administrasi server. - Menjalankan proyek web atau aplikasi pribadi yang sesuai aturan. - Eksperimen pemrograman dan pengembangan.
Fitur
Fitur berikut merupakan gambaran layanan yang direncanakan. Fitur aktual bergantung pada server dan pengumuman pengelola.
Pilihan akses RDP dan VPS.
Lingkungan Windows dan/atau Linux jika tersedia.
Akses jarak jauh.
Panduan penggunaan dasar.
Informasi status dan masa aktif melalui kanal resmi komunitas.
Catatan: Kata "Free" berarti akses gratis hanya jika dinyatakan tersedia oleh pengelola. Kuota, spesifikasi, masa aktif, dan syarat dapat berubah. Tidak ada jaminan layanan 24/7 atau kapasitas tertentu kecuali diumumkan secara resmi.
Cara Mendapatkan Akses
Baca pengumuman terbaru dari kanal resmi IPULCLOUD / Ipul Community.
Periksa apakah pendaftaran sedang dibuka.
Ikuti prosedur pendaftaran yang diumumkan pengelola.
Tunggu konfirmasi dan petunjuk akses.
Gunakan server sesuai aturan layanan.
Jangan mengirim password, private key, kode OTP, atau token rahasia di grup publik maupun kolom komentar.
Cara Terhubung ke RDP
Setelah akses RDP resmi diberikan:
Buka aplikasi Remote Desktop yang tepercaya pada perangkat.
Masukkan alamat server dan port yang diberikan pengelola.
Masukkan nama pengguna sesuai petunjuk.
Masukkan password secara pribadi pada aplikasi.
Putuskan koneksi setelah selesai menggunakan server.
Alamat server, port, dan akun tidak dicantumkan di README publik. Gunakan hanya detail yang diberikan langsung oleh pengelola.
Cara Terhubung ke VPS
Setelah akses VPS resmi diberikan:
Gunakan aplikasi SSH tepercaya.
Masukkan alamat IP/hostname dan port SSH dari pengelola.
Login memakai metode autentikasi yang telah disediakan.
Jalankan hanya perintah yang dipahami dan diizinkan.
Keluar dari sesi SSH setelah selesai.
Contoh format koneksi (ganti dengan detail resmi milikmu):
ssh USERNAME@SERVER_HOST
Jangan menaruh password atau private key ke dalam file README, repositori publik, atau pesan umum.
Aturan Penggunaan
Pengguna wajib: - Mematuhi hukum yang berlaku dan ketentuan penyedia infrastruktur. - Menggunakan server untuk kegiatan yang sah dan bertanggung jawab. - Menjaga kerahasiaan akun dan data akses. - Menghormati batas CPU, RAM, penyimpanan, bandwidth, dan masa aktif. - Menghubungi pengelola jika menemukan masalah keamanan.
Dilarang: - Mengakses sistem, akun, atau data milik orang lain tanpa izin. - Menyebarkan malware, phishing, spam, atau melakukan penipuan. - Melakukan serangan jaringan, pemindaian yang tidak diizinkan, atau mengganggu layanan. - Menambang cryptocurrency atau menjalankan aktivitas yang dilarang pengelola. - Menjual, memindahtangankan, atau membagikan akun tanpa izin. - Menggunakan server untuk melanggar hukum atau merugikan pihak lain.
Pengelola dapat membatasi atau menghentikan akses jika terjadi pelanggaran atau penyalahgunaan.
Keamanan Akun
Gunakan password yang kuat dan unik.
Jangan membagikan kredensial, token, OTP, atau private key.
Aktifkan autentikasi tambahan jika tersedia.
Jangan memasukkan kredensial ke skrip yang dibagikan secara publik.
Simpan salinan data penting sendiri; jangan menganggap server gratis sebagai tempat backup permanen.
Laporkan dugaan akses tidak sah kepada pengelola.
Batasan Layanan
Layanan gratis dapat memiliki: - Kuota pengguna atau sumber daya yang terbatas. - Masa aktif atau jadwal penggunaan tertentu. - Perubahan spesifikasi dan ketersediaan. - Pemeliharaan atau penghentian sementara. - Penghapusan instance sesuai kebijakan yang diumumkan.
Sebelum menyimpan data penting, pastikan memahami kebijakan penyimpanan dan penghapusan data dari pengelola.
